# Corpus semilla — dominio: llm

## Cómo funciona un modelo de lenguaje grande
<!-- subcategoria: fundamentos | dificultad: intermedio | idioma: es -->
Un modelo de lenguaje grande (LLM) es un transformer decoder-only entrenado para predecir el siguiente token: dado un contexto x_1..x_t, estima p(x_{t+1} | x_1..x_t) y se optimiza minimizando la entropía cruzada sobre billones de tokens. El texto se convierte en tokens con un tokenizador BPE, cada token se proyecta a un embedding y una pila de bloques de self-attention causal y redes feed-forward construye representaciones contextuales. El entrenamiento ocurre en etapas: pre-entrenamiento auto-supervisado (conocimiento y lenguaje), instruction tuning o SFT con pares instrucción-respuesta (formato de asistente) y alineación con preferencias humanas mediante RLHF o DPO. Las leyes de escalado muestran que la pérdida decrece como ley de potencia con parámetros, datos y cómputo; Chinchilla estableció que el óptimo usa unos 20 tokens por parámetro. En inferencia, el KV cache evita recomputar el prefijo y la ventana de contexto limita cuánta información puede usar el modelo en una sola consulta.

## RAG, fine-tuning con LoRA y alucinaciones
<!-- subcategoria: aplicaciones | dificultad: avanzado | idioma: es -->
Para especializar un LLM hay dos caminos complementarios. Retrieval-Augmented Generation (RAG) recupera fragmentos relevantes de una base de datos vectorial mediante similitud de embeddings y los inserta en el prompt: actualiza el conocimiento sin reentrenar y permite citar fuentes. El fine-tuning ajusta los pesos; LoRA congela la matriz original W y aprende una actualización de bajo rango ΔW = B·A con r ≪ d, reduciendo los parámetros entrenables a menos del 1 %, y QLoRA además cuantiza el modelo base a 4 bits para caber en una sola GPU. Las alucinaciones —respuestas fluidas pero falsas— surgen porque el modelo maximiza plausibilidad, no veracidad; se mitigan con RAG, instrucciones que permiten responder 'no sé', chain-of-thought para problemas de varios pasos y evaluación sistemática con conjuntos de prueba propios. Few-shot e in-context learning permiten adaptar el comportamiento con ejemplos en el prompt, sin tocar los pesos.
