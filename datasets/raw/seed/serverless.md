# Corpus semilla — dominio: serverless

## Serverless Framework e infraestructura declarativa
<!-- subcategoria: framework | dificultad: intermedio | idioma: es -->
El Serverless Framework define aplicaciones serverless de forma declarativa en un archivo serverless.yml: funciones, los eventos que las disparan (HTTP, colas, cron), recursos de infraestructura y permisos IAM. Con un solo comando empaqueta el código y lo despliega, traduciendo la configuración a CloudFormation en AWS. Abstrae la complejidad de aprovisionar API Gateway, Lambda, roles y políticas. Soporta múltiples proveedores y un ecosistema de plugins (offline para desarrollo local, warmup contra arranques en frío). Encaja en flujos de infraestructura como código y CI/CD, versionando la definición de la arquitectura junto al código.
