# Corpus semilla — dominio: full_stack

## Arquitectura de una aplicación web full stack
<!-- subcategoria: arquitectura_web | dificultad: intermedio | idioma: es -->
Una aplicación full stack se divide en frontend, backend y persistencia. El frontend (React, Vue o Angular, usualmente con TypeScript) renderiza la interfaz, gestiona el estado de la aplicación y consume APIs; frameworks como Next.js añaden renderizado del lado del servidor (SSR) y generación estática para mejorar el tiempo de carga y el SEO. El backend (Node.js con Express, Python con FastAPI o Django) expone endpoints REST o GraphQL, valida entradas, aplica reglas de negocio y autenticación (sesiones o JWT con OAuth). La capa de datos usa un ORM como Prisma o SQLAlchemy sobre PostgreSQL, con migraciones versionadas. Para tiempo real se usan WebSockets. El diseño responsivo con CSS moderno o Tailwind adapta la interfaz a móviles. Una buena separación de responsabilidades permite desplegar frontend y backend de forma independiente y escalar cada capa según su carga.

## Estado, componentes y rendimiento en React
<!-- subcategoria: frontend | dificultad: intermedio | idioma: es -->
En React la interfaz es una función del estado: cada componente recibe props, mantiene estado local con useState y declara efectos secundarios con useEffect. Cuando el estado cambia, React vuelve a renderizar y reconcilia el DOM virtual con el real aplicando solo las diferencias. El estado compartido entre muchos componentes se eleva a un ancestro común o se gestiona con Context, Zustand o Redux; el estado del servidor (datos remotos) conviene manejarlo con librerías como TanStack Query, que cachean, deduplican y revalidan peticiones. Para rendimiento: memoizar cálculos costosos con useMemo, estabilizar callbacks con useCallback, dividir el bundle con carga diferida (lazy) y virtualizar listas largas. Herramientas como Vite aceleran el desarrollo con recarga en caliente, y las pruebas de componentes con Testing Library verifican el comportamiento desde la perspectiva del usuario.
